# Dynamic Earth 3D v2.0E

Tutki Maata, Kuuta ja Aurinkoa · Explore Earth, Moon & Sun

Open the simulator: open the repository's GitHub Pages website when deployment is enabled, or download index.html using GitHub's Download raw file action and open it locally. The file embeds its JavaScript, styles, six maps and legal notices and runs offline. A repository ZIP also contains the small guides and notices; extract before opening index.html. No build or installation is needed.

Intended Pages address (deployment must be verified separately): https://jh-scienceworks.github.io/Dynamic-Earth-3D/

FI: Valitse yläpalkista FI/EN. Aloita tutkiminen tai seuraa kysymyspolkua. Vedä kiertääksesi ja rullaa zoomataksesi. Valitse Vuodenajat tai Todellinen mittakaava tutkimusvalikosta. Offline-käyttö: lataa index.html ja avaa se selaimessa; säilytä krediitit mukana.

EN: Choose FI/EN, start exploring or follow a question. Drag to rotate and scroll to zoom. Select Seasons or True scale from the controls. For offline use, download index.html and open it in a browser; preserve credits.

Ten studies / kymmenen tutkimusta: Maa / Earth; Taivas / Sky; Todellinen mittakaava / True scale; Kuun vaiheet / Moon phases; Kuun pinta / Moon surface; Pimennykset / Eclipses; Maan sisärakenne / Earth interior; Laattatektoniikka / Plate tectonics; Magneettikenttä ja aurinkotuuli / Magnetic field and solar wind; Aurinko / Sun.

Read [teacher quick start](TEACHER_QUICKSTART_FI_EN.md), [science and limitations](SCIENCE_AND_LIMITATIONS.md) and [credits and licenses](CREDITS_AND_LICENSES.md). JavaScript and WebGL are required. This is educational software, with approximate models and schematic guides. No tracking/analytics or runtime CDN/API is required.

The orbit guide is a schematic projection. It does not depict the orbit's exact three-dimensional orientation or shape.

The project was designed, iterated and manually reviewed under a teacher's direction, with OpenAI ChatGPT models and Codex used in software development, visual implementation, documentation and testing. Scientific sources and model limitations are acknowledged separately.

Project code: MIT; third-party maps, database and libraries retain their separate terms. No institutional endorsement or independent scientific certification is claimed. The public repository contains the generated user distribution, guides and legal notices. Development source/history is preserved separately by the owner.
