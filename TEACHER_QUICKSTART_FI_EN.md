# Dynamic Earth 3D v2.0E — pikaohje / quick start

Tutki Maata, Kuuta ja Aurinkoa / Explore Earth, Moon & Sun

FI: Pura koko Standalone-ZIP omaan kansioon. Avaa Dynamic-Earth-3D.html kaksoisnapsauttamalla tai selaimen Ctrl+O-valinnalla. Windowsin Avaa sovelluksessa -valinnalla voit valita Firefoxin, Edgen tai Chromen. Selain tarvitsee JavaScriptin ja toimivan WebGL:n. Internetiä, asennusta, Nodea tai palvelinta ei tarvita. Lähdelinkit tarvitsevat verkon vain, jos avaat ne itse. Tämä ohje kertoo avaustavan; selainten toteutuneet testit on raportoitu erikseen.

Valitse FI/EN yläpalkista. Aloita tutkiminen avaa kymmenen tutkimuksen valikon; Aloita kysymyksestä tarjoaa ohjattuja polkuja. Vedä 3D-näkymää kiertääksesi, käytä rullaa zoomaukseen ja palauta kamera sen painikkeella. Ajan säätimet ohjaavat simulaatiota. Vuodenajat-yleiskuvassa valitse ajankohta ja siirrä aika tutkimukseen erillisellä painikkeella. Todellinen mittakaava -tutkimuksessa kokeile Maa–Kuu- ja Aurinko–Maa-vertailuja, etäisyyslukemaa ja valinnaista rataopastetta.

Rataopaste on havainnollistava projektio. Se ei kuvaa radan tarkkaa kolmiulotteista suuntaa tai muotoa. Keskipisteiden väliset etäisyydet ovat mallin laskettuja tai dokumentoituja arvoja; opasteen kuvasta ei pidä mitata radan muotoa.

EN: Extract the complete Standalone ZIP to a folder. Double-click Dynamic-Earth-3D.html, use Ctrl+O in your browser, or Windows Open with to choose Firefox, Edge or Chrome. JavaScript and working WebGL are required. No internet, installation, Node or server is required. Source links need a connection only when you open them. These are opening instructions; tested browser coverage is reported separately.

Choose FI/EN in the header. Start exploring opens the ten studies; Start from a question opens guided paths. Drag to rotate, scroll to zoom, and use the camera reset button. Time controls drive the simulation. In Seasons, choose a date and explicitly apply it to the study. In True scale, try Earth–Moon and Sun–Earth presets, centre-distance readings and the optional orbit guide.

The orbit guide is a schematic projection. It does not depict the orbit's exact three-dimensional orientation or shape. Numerical centre-to-centre distances are calculated/documented model values; the guide is not a way to measure orbital geometry.

Before class / Ennen tuntia: open the file on the classroom computer, test rotation and language, select normal quality if needed, and try the chosen question path. Read SCIENCE_AND_LIMITATIONS and retain CREDITS_AND_LICENSES when sharing. Physical mobile devices and screen readers require separate testing. Firefox manual checklist: open file with network disconnected; verify textured globe; FI/EN; all ten studies; seasons and question path; both scale presets, distance/orbit toggles and explanatory note; continuous Earth/Moon motion; no blank WebGL view.
